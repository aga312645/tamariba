HTML（HyperText Markup Language）は、ウェブページの骨組みを作るための言語です。タグと呼ばれる記号（`< >`）でテキストを囲むことで、ブラウザに「ここは見出し」「ここは画像」と伝えます。

基本的には、開始タグ（`<タグ名>`）と終了タグ（`</タグ名>`）をセットで使います。

ウェブ制作で最初によく使う**主なHTMLタグ**を、役割ごとに整理して紹介します。

---

## 1. ページの基本構造を作るタグ

すべてのウェブページの土台となるタグです。

* **`<html>`**：HTML全体の始まりと終わりを示します。
* **`<head>`**：ページの管理情報（タイトルや文字コードなど、画面には見えない部分）を入れます。
* **`<body>`**：実際にブラウザの画面に表示される中身を入れます。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>ページのタイトル</title>
</head>
<body>
    </body>
</html>

```

---

## 2. テキストを装飾・構造化するタグ

文章を書く際、最も頻繁に使う重要タグです。

* **`<h1>` 〜 `<h6>`（見出し）**
* `<h1>`が一番大きく重要な見出しで、数字が大きくなるにつれて小見出しになります。


* **`<p>`（段落 - Paragraph）**
* ひと塊の文章（段落）を表します。前後に自動で少し余白が入ります。


* **`<br>`（改行 - Break）**
* 文章を途中で改行します。これには**終了タグ（`</br>`）がありません**。


* **`<strong>`（太字・強調）**
* 文字を太字にし、ブラウザや検索エンジンに「ここが重要」と伝えます。



```html
<h1>初心者のためのHTML講座</h1>
<h2>1. タグの基本</h2>
<p>HTMLはタグを使って書きます。<br>文字を<strong>太字</strong>にすることも簡単です。</p>

```

---

## 3. リンクと画像を表示するタグ

ウェブサイトに欠かせない、他ページへの移動や画像表示のタグです。

* **`<a>`（リンク - Anchor）**
* `href`（エイチレフ）という属性を使って、飛び先のURLを指定します。


* **`<img>`（画像 - Image）**
* `src`（ソース）で画像の場所、`alt`（オルト）で画像の説明を指定します。このタグも**終了タグがありません**。



```html
<a href="https://example.com">公式サイトはこちら</a>

<img src="logo.png" alt="会社のロゴマーク">

```

---

## 4. リスト（箇条書き）を作るタグ

箇条書きを作る時は、親タグと子タグを組み合わせて使います。

* **`<ul>`（箇条書き・順序なし）**：行頭に「・」がつきます。
* **`<ol>`（番号付き箇条書き）**：行頭に「1. 2. 3.」と番号がつきます。
* **`<li>`（リストの項目）**：`<ul>`や`<ol>`の中で、具体的な項目を並べるために使います。

```html
<ul>
    <li>リンゴ</li>
    <li>バナナ</li>
    <li>ブドウ</li>
</ul>

```

---

## 5. グループ分け（レイアウト）に使うタグ

デザインを整えたり、エリアごとにまとめたりする時に重宝するタグです。

* **`<div>`（ディブ）**
* 特に意味は持たない、**「塊（ブロック）」を作るためのタグ**です。CSSでデザインを当てる際の枠組みとして、Web制作の現場で最も多用されます。


* **`<span>`（スパン）**
* 文章の一部など、**「行内の一部」をグループ化するためのタグ**です。「この1文字だけ赤色にしたい」という時などに使います。



```html
<div class="box">
    <p>ここが塊になります。文章の<span style="color: red;">一部だけ</span>色を変えることもできます。</p>
</div>

```

ユーザーの動き（クリック、ホバー、画面のスクロールなど）に反応して、ページのデザインが変わったり、画面が切り替わったりする仕組みですね。

これを実現するために、Webサイトでは主に「HTMLのタグ本来の機能」**、**「CSS（見た目を整える言語）」**、そして**「JavaScript（プログラム）」の3つを組み合わせて使っています。

具体的にどのように動いているのか、仕組みごとに分けて紹介します。

---

## 1. タグ本来の機能（クリックで移動）

「アイコンを押したらホームページに戻る」「別のページに飛ぶ」というのは、HTMLの **`<a>`タグ（リンクタグ）** の標準の機能です。

```html
<a href="index.html">
    <img src="logo.png" alt="ホームへ戻る">
</a>

```

ユーザーがクリックした瞬間、ブラウザが「指定されたURLのページを新しく読み込む」という動きをしています。

---

## 2. CSSによる変化（デザインの一時的な切り替え）

「ボタンにマウスを乗せたら（ホバーしたら）色が変わる」「クリックした瞬間だけボタンが沈む」といった、**見た目のちょっとした変化**は **CSS** という言語が担当しています。

CSSには「マウスが乗っているとき（`:hover`）」や「クリックされている瞬間（`:active`）」だけデザインを変える仕組みがあります。

```css
/* 通常のボタン */
.button {
    background-color: blue;
    transition: 0.3s; /* 滑らかに変える */
}

/* マウスが乗ったとき（ユーザーの動きに反応） */
.button:hover {
    background-color: red; /* 赤色に変わる */
}

```

ページの読み込みは発生せず、その場でデザインが一瞬で切り替わります。

---

## 3. JavaScriptによる変化（高度な動的ギミック）

ページを新しく読み込むわけではないのに、「画面の一部がダイナミックに変化する」場合は、プログラミング言語の **JavaScript（ジャバスクリプト）** が裏で動いています。

ユーザーの「～したとき（イベント）」をきっかけに、HTMLやCSSをリアルタイムに書き換える役割を持っています。

### よくある具体例

* **ハンバーガーメニュー（スマホ用のメニュー）**
三本線のアイコンをクリックすると、横からメニューがスルスルと飛び出してくる。
* **ポップアップ表示（モーダルウィンドウ）**
ボタンを押すと、画面が暗くなって「本当に削除しますか？」といった確認画面が中央に浮かび上がる。
* **いいねボタン**
ハートのアイコンを押すと、ページを切り替えずにハートが赤くなり、数字が「1」増える。
* **スクロール連動**
画面を下にスクロールしていくと、フワッと画像や文字が現れる。

---

## まとめ

Webサイトの変化は、以下のように役割分担されています。

| ユーザーの動き | 変化の裏側（仕組み） | 主な役割 |
| --- | --- | --- |
| **クリックして別ページへ** | HTML（`<a>`タグ） | ページの移動・切り替え |
| **マウスを乗せて色が変わる** | CSS（`:hover`など） | 見た目の装飾・演出 |
| **その場で形や内容が変わる** | JavaScript | 高度な仕掛けやアニメーション |

このように、Webページは静的な骨組み（HTML）に、装飾（CSS）と、ユーザーの動きに反応する仕組み（JavaScript）が合体することで、生き生きとした動きを表現しています。

普通の「押したら別のページに飛ぶリンク」には、先ほど少し登場した **`<a>`タグ（アンカータグ）** を使います。

これがWebサイトで最もよく使われる、基本中の基本のリンクです。

---

## 基本的な書き方

HTMLでは、以下のように記述します。

```html
<a href="移動先のURL">画面に表示する文字</a>

```

### 具体的な例

例えば、Googleのトップページに飛ぶリンクを作りたい場合は、このように書きます。

```html
<a href="https://www.google.com">Googleのサイトへ移動します</a>

```

これをブラウザで表示すると、おなじみの「下線のついた青い文字」になり、クリックするとGoogleのページに切り替わります。

---

## よく一緒に使われる便利な「設定」

`<a>`タグには、少し設定（属性）を足すだけで、飛び方の挙動を変えることができます。特によく使う2つを紹介します。

### 1. 新しいタブで開きたいとき（`target="_blank"`）

リンクを押したときに、今のページを残したまま**別のタブで開きたい**場合は、`target="_blank"`（ターゲット・ブランク）を書き加えます。

```html
<a href="https://www.google.com" target="_blank" rel="noopener noreferrer">Googleを新しいタブで開く</a>

```

> 💡 **補足**：`target="_blank"` を使うときは、セキュリティとページの動作を軽くするために `rel="noopener noreferrer"` というお守りのようなコードをセットで書くのが現在のWeb制作の共通ルールになっています。

### 2. ページ内の「特定の場所」に一瞬でジャンプしたいとき

別のページではなく、**同じページ内の下の方（例えば「お問い合わせフォーム」など）に一瞬でスクロールさせたい**場合にも`<a>`タグが使えます。

まず、飛び先の目印にしたいタグに `id="名前"` をつけ、リンク側の `href` に `#名前` と指定します。

```html
<a href="#contact-section">お問い合わせへジャンプ</a>

<div id="contact-section">
    <h2>お問い合わせフォーム</h2>
</div>

```

このように、一般的なWebサイトにある「押したら飛ぶ」という動きは、ほぼすべてこの `<a>` タグが担っています。
